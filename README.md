# Skills Copilot Codespaces VS Code

Dépôt d'expérimentation et d'apprentissage GitHub Copilot / Codespaces.

## Objet

Ce projet sert de laboratoire d'apprentissage pour découvrir et tester les bonnes pratiques de développement assisté par IA dans un environnement Codespaces / VS Code.

## Contenu

- expérimentation GitHub Copilot
- environnement de développement reproductible
- prise en main des outils GitHub et workflow de collaboration

## Position dans le portfolio

Ce dépôt ne représente pas un projet produit final ; il sert surtout à démontrer mon apprentissage et mon utilisation de l'écosystème GitHub + IA dans un cadre de dev moderne.
